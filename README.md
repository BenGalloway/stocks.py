# Stocks.py README
## DISCLAIMER
This is in now way intended as financial advice.  This is in no way designed to influence your investments or investment strategy.
This is intended for the sole purpose of creating a tool that is customizable and searchable in a personal capacity only.
### Intent
After day trading futures for roughly 6 years, then switching to being a less involved investor I found myself looking at finviz far too often to find potential target.  So I made something that could do it for me. That's it.  Just a screener with my default paramaters coded into it.  Feel free to clone, fork and change to your hearts content.
### Usage
- Clone it
- Run 'pip install -r requirements.txt'
- Run 'python(3) main.py'
- The screener will pick up where the most recent .db file left off.
### Optional
- Delete .db file to run a fresh scan of your own
- **WARNING** This will take a good amount of time estimated 4-8 hours depending on your paramaters
